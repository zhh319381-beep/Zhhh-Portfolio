02

重点项目：导演小助手

这是作品集的核心产品案例，用来展示 PRD、Figma 原型、Agent 工作流和 AI 视频创作理解。

Core

导演小助手｜AI 视频创作 Agent

面向影视创作者与新手小白的 AI 辅助工具，支持用户通过自然语言输入或上传参考图片，直接转化为影视级的高精度 Prompt 与镜头分镜。

问题
传统创作者或新手有创意但缺乏 AI 提示词工程经验，难以将复杂的视觉想法精准转化为 AI 模型能听懂的专业语言。
方案
自然语言 / 图生图输入 -> 多模态意图解析 -> 镜头语言与参数融合 -> 专业 Prompt 输出 -> 效果微调与迭代。
产出
PRD、Figma 原型、Coze Agent 工作流、视频生成链路说明。
Support

AI 视频模板工作流｜创作经验沉淀

将成熟的 AI 视频创作经验结构化为可直接套用的模板工作流，帮助创作者简化创作链路，快速复现商业级视频效果。

沉淀内容
覆盖广告、电商、特效、宣传片等多场景的视频模板，内置成熟的运镜、风格与控制参数。
方法结构
创作目标 -> 视觉参考 -> 提示词结构 -> 模型生成 -> 问题修正 -> 成片。
价值
为产品功能提供真实的创作经验支撑，降低用户使用门槛，提升生成效率与成片率。
Proof

AI 商业影像作品集｜场景验证

用真实作品展示影像审美、AI 视频执行能力，以及对不同创作场景的理解。

作品类型
薯片广告、榛果巧克力广告、苹果降噪耳机广告、电商视频、变装视频、蜘蛛侠变身、粒子化、宣传片。
创作重点
产品质感、风格统一、主体稳定、镜头节奏、情绪表达和最终完成度。
价值
在不同影像场景中验证 AI 视频工具的可用边界和创作机会。

Interactive Agent
